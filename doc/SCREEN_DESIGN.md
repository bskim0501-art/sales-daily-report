## 2. 공통 사항

### 2.1 레이아웃 구조

```
┌──────────────────────────────────────────────┐
│  [로고]  영업 일일 보고 시스템    [사용자명] [로그아웃] │  ← 헤더 (고정)
├────────┬─────────────────────────────────────┤
│        │                                     │
│  사이드 │         메인 콘텐츠 영역              │
│  메뉴  │                                     │
│        │                                     │
└────────┴─────────────────────────────────────┘
```

### 2.2 사이드 메뉴 구성

**영업사원**
- 내 보고서
- 보고서 작성

**관리자**
- 팀 보고서
- 고객 마스터
- 영업사원 마스터

### 2.3 공통 컴포넌트

| 컴포넌트 | 설명 |
|----------|------|
| 페이지네이션 | 목록 화면 하단, 페이지당 20건 기본 |
| 확인 다이얼로그 | 삭제·제출 등 비가역 작업 전 confirm 팝업 |
| 토스트 메시지 | 저장 성공/실패, 제출 완료 등 결과 알림 |
| 로딩 스피너 | API 호출 중 화면 블로킹 표시 |

### 2.4 보고서 상태 표시

| 상태 | 표시 | 색상 |
|------|------|------|
| draft | 작성중 | 회색 |
| submitted | 제출완료 | 파란색 |
| confirmed | 확인완료 | 초록색 |

## 5. SCR-011 보고서 작성·수정

### 기본 정보

| 항목 | 내용 |
|------|------|
| 화면 ID | SCR-011 |
| 화면명 | 보고서 작성·수정 |

| URL | `/reports/new` (작성), `/reports/:id/edit` (수정) |

### 화면 레이아웃

```
보고서 작성                                [임시저장]  [제출]
─────────────────────────────────────────────────────
보고 날짜: [2025-05-10]

━━━ 방문 내역 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┌──────────────────────────┬────────────────────────┐
│ 고객사                    │ 방문 내용               │
├──────────────────────────┼────────────────────────┤
│ [고객사 선택 ▼]           │ [                    ] │
├──────────────────────────┼────────────────────────┤
│ [고객사 선택 ▼]           │ [                    ] │
└──────────────────────────┴────────────────────────┘
                                         [+ 행 추가]

━━━ 과제·상담 (Problem) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┌─────────────────────────────────────────────┬─────┐
│ 내용                                         │ 분류 │
├─────────────────────────────────────────────┼─────┤
│ [                                         ] │ [▼] │
└─────────────────────────────────────────────┴─────┘
                                         [+ 항목 추가]

━━━ 내일 할 일 (Plan) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
┌─────────────────────────────────────────┬──────────┐
│ 내용                                     │ 우선순위  │
├─────────────────────────────────────────┼──────────┤
│ [                                     ] │ [중간 ▼]  │
└─────────────────────────────────────────┴──────────┘
                                         [+ 항목 추가]
```

### 입력 항목 — 헤더

| 항목 | 타입 | 필수 | 유효성 검증 |
|------|------|------|------------|
| 보고 날짜 | date picker | ✅ | 미래 날짜 불가, 이미 제출된 날짜 선택 불가 |

### 입력 항목 — 방문 내역 (행 반복)

| 항목 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 고객사 | select (고객 마스터) | ✅ | 활성 고객만 표시, 검색 가능 |
| 방문 내용 | textarea | ✅ | 최대 500자 |
| 방문 결과 | textarea | - | 최대 200자 |
| 삭제 버튼 | icon button | - | 행 제거 (최소 1행 유지) |

### 입력 항목 — 과제·상담 (행 반복)

| 항목 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 내용 | textarea | ✅ | 최대 500자 |
| 분류 | select | - | 가격 / 납기 / 기술 / 경쟁사 / 기타 |
| 삭제 버튼 | icon button | - | 행 제거 |

### 입력 항목 — 내일 할 일 (행 반복)

| 항목 | 타입 | 필수 | 비고 |
|------|------|------|------|
| 내용 | textarea | ✅ | 최대 500자 |
| 우선순위 | select | - | 높음 / 중간 / 낮음 (기본: 중간) |
| 삭제 버튼 | icon button | - | 행 제거 |

### 동작

| 액션 | 동작 |
|------|------|
| + 행 추가 | 해당 섹션에 빈 행 1개 추가 |
| 삭제 버튼 | 해당 행 제거 (방문 내역은 최소 1행 유지) |
| 임시저장 | status=draft로 저장, 현재 화면 유지, 성공 토스트 표시 |
| 제출 | 필수 항목 유효성 검증 → status=submitted로 저장 → SCR-010으로 이동 |
| 제출 후 수정 | submitted 상태에서는 편집 불가 (SCR-011 접근 차단) |

### 유효성 검증 규칙

- 방문 내역은 최소 1행 이상 필수
- 고객사 미선택 상태로 제출 불가
- 과제·상담 또는 내일 할 일이 0건이어도 제출 가능

  1. [가격] 삼성전자 단가 협의 필요 — 경쟁사 대비 15% 이상 차이
     └ 💬 김팀장 (2025-05-09 19:12): 영업본부와 협의 후 특별 단가 적용 검토하겠습니다.

━━━ 내일 할 일 (Plan) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  1. [높음] 삼성전자 2차 미팅 일정 확정 메일 발송
     └ 💬 김팀장 (2025-05-09 19:15): 오전 중으로 확인 부탁드립니다.
  2. [중간] LG화학 발주 계약서 초안 작성

| 내일 할 일 | 순번, 우선순위 태그, 내용, 댓글 목록 |
